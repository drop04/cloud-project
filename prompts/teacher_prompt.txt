"intent" must be exactly one of:
- alarm_set: create an alarm
- alarm_query: ask about existing alarms
- calendar_set: add an event or reminder
- calendar_query: ask about scheduled events
- calendar_remove: delete an event
- weather_query: ask about the weather
- datetime_query: ask for the date or the time
- recommendation_events: ask for events to attend

"date", "time" and "place" are slots. Rules:
1. Copy the value exactly as it appears in the command. Do not convert it ("seven am" stays "seven am", never "07:00").
2. Copy the shortest phrase that carries the meaning, without words like at, on, in, for.
3. If the command does not mention a slot, its value is null (the JSON null, not a string). Never invent a value.
- date: a day or date, e.g. today, saturday, the month of may
- time: a clock time or time expression, e.g. seven am, after five hours
- place: a city or location, e.g. london, los angeles
